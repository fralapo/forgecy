# Playbook sources

The playbooks in this folder are short adaptations, rewritten for Forgecy's agents, of skills from [fralapo/awesome-agent-skills](https://github.com/fralapo/awesome-agent-skills):

| Playbook         | Adapted from                                      |
| ---------------- | ------------------------------------------------- |
| `social-content` | `social-algorithm`                                |
| `positioning`    | `marketing-mba`                                   |
| `copywriting`    | `creative-director`, `public-speaking-persuasion` |
| `imagery`        | `image-gen-prompts`                               |
| `website-review` | `ux-ui-expert`, `geo-ai-visibility`               |
| `slide-design`   | `ux-ui-expert`                                    |
