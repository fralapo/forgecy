# Architecture decisions (ADR)

One page for each decision that changes or clarifies the technical specification. Format: context, decision, consequences. Sequential numbering; never rewrite an accepted ADR: if it changes, write a new one that supersedes it.

Numbering is sequential. One duplicate is grandfathered (two ADRs were accepted as 0007 on 2026-10-06); never add another, and always refer to an ADR by its full file name (for example `0007-agent-playbooks.md`), not by the bare number.
